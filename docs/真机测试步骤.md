# 华为 Mate 40 Pro / 鸿蒙 4.2 / 夸克测试步骤

1. 将测试 APK 传到手机，安装“日语实时字幕”。测试版签名仅用于验证。
2. 默认选择“本机演示”，无需注册服务账号。
3. 点击开始，先完成悬浮窗授权，返回后再点开始。
4. 完成录音权限与系统捕获授权；权限名称由系统决定，本应用不读取麦克风。
5. 切到夸克，播放有声音的视频。音量条在主界面可查看；悬浮窗等待非静音音频。
6. 有声音后约 2 秒出现“【演示】”固定文字，说明应用采到了非静音内部音频。它不是影片对白的翻译。
7. 若无字，回主界面看输入音量和状态。确认影片正在播放，再用其他播放器作对照；可能是目标 App 不允许采集，不能据此断定手机或模型故障。
8. 戴耳机重复测试，记录有线或蓝牙类型，确认无需外放。
9. 拖动字幕标题改变位置；横竖屏分别测试。字幕范围外应能正常操作影片。
10. 点击暂停，确认音量和音频上传停止；继续后从当前声音重新开始。
11. 点击清空，确认旧字消失。停止后悬浮窗与前台通知都应消失。
12. 使用系统停止捕获、撤回悬浮窗权限和锁屏，检查应用能正确结束或报告停止。
13. 在 `docs/device-matrix.md` 记录夸克版本、系统版本、路由、声音与窗口结果。

## 后端联调

1. 电脑运行 `scripts/start-backend.ps1`，确保 `.env` 中 `PROVIDER=mock`。
2. 手机开启 USB 调试，并在手机上授权这台电脑。
3. 电脑执行 `scripts/connect-phone.ps1` 建立 USB 端口反向转发。
4. App 选择“连接翻译服务”，地址使用 `http://127.0.0.1:8765`。
5. 从自己的 `backend/.env` 取出应用访问令牌，填到手机并保存；不需要 Azure 账号。
6. 点击开始，播放影片。此模式将真实内部音频上传到电脑，后端仍只返回固定演示文字。
7. 测试拔掉 USB 后的重连状态。接回并恢复端口转发后，应该跟随当前声音，不回放长时间旧字幕。

## 0.2 本地模型真实翻译

1. 用 `scripts/start-local-backend.ps1` 替代模拟启动脚本，等待模型加载完成；电脑需保持运行。
2. 手机 USB 调试授权后，执行 `scripts/connect-phone.ps1 -Install` 安装新版并建立转发。
3. 仍选择“连接翻译服务”，填写同一本机地址和应用访问令牌。服务 `/health` 应显示 `provider=local`、`demo=false`。
4. 授权采集后播放日语影片，检查字幕是否随真实对白变化；模型会等待语音和稳定片段，不能用固定演示文字判断识别成功。
5. 重复上述采音、耳机、窗口、暂停停止与断线步骤，记录实际结果。完整说明见 `docs/本地模型联调.md`。
