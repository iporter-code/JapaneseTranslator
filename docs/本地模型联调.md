# 0.2 本地模型联调

## 已实现的链路

手机内部 PCM 音频 → USB 反向端口转发 → 后端 WebSocket → Silero VAD 分句 → Whisper large-v3-turbo 识别日语 → Hy-MT2-1.8B 翻译简体中文 → 原协议返回 → 手机悬浮字幕。

电脑服务已用公开日语音频按真实播放速度验证。手机端仍待华为 Mate 40 Pro / 鸿蒙 4.2 / 夸克实测。0.2 APK 的本机演示模式仍是固定测试文字；只有连接 `provider=local` 的服务时才是真实识别翻译。

本版手机运行采音、网络和悬浮窗，模型运行在电脑。电脑睡眠、服务退出或 USB 断开都会中断翻译。普通 Android 应用不能解除其他 App 和系统的采集限制，因此不承诺所有手机、所有 App 通用。

后续已增加不接 USB 的公网 HTTPS 通道，手机只安装现有 APK 即可连接；参见 [电脑作为无线翻译服务器](电脑作为无线翻译服务器.md)。以下 USB 步骤仍可用于低延迟本地调试。

## 在当前电脑启动

1. 关闭先前启动的模拟后端，避免占用 8765 端口。
2. 在项目根目录执行：

```powershell
.\scripts\start-local-backend.ps1
```

3. 等待 `Application startup complete`。启动过程检查模型文件和 CUDA 后端，加载、预热识别及翻译模型。默认使用 RTX 4050；不静默回退 CPU。
4. 服务监听 `127.0.0.1:8765`，内部翻译进程监听 `127.0.0.1:8788`，使用本次启动随机生成的内部令牌。任一端口被其他进程占用时直接失败，不复用未知服务。
5. 在浏览器或 PowerShell 查看 `http://127.0.0.1:8765/health`，应为 `provider: local`、`demo: false`、`ready: true`。该接口不返回应用令牌。
6. 手机连接 USB，开启 USB 调试，在手机上允许这台电脑调试。另开终端执行：

```powershell
.\scripts\connect-phone.ps1 -Install
```

7. 脚本选择唯一已授权设备、设置端口反向转发、安装 `artifacts/日语实时字幕-0.2.0-local.apk` 并打开应用。有多个设备时用 `-Serial` 明确指定；可用 `-Adb` 指定 ADB 路径。没有设备时会报告原因，不标记联调通过。
8. 手机选择“连接翻译服务”，地址填 `http://127.0.0.1:8765`。从本机 `backend/.env` 读取 `APP_ACCESS_TOKEN` 的值并在手机保存。它是自己后端的访问令牌，无需购买服务或注册云账号，不是模型密码。不要把令牌发送到聊天或提交 Git。
9. 点击“授权并开始”，依次完成悬浮窗、录音权限和系统捕获授权，然后打开夸克播放日语视频。连接真实服务后应显示“正在翻译”，而非“演示字幕”。
10. 先看主界面音量是否变化。没有可采集音频时，模型不会凭空获得影片声音；使用另一播放器作对照，记录目标 App 限制。
11. 测试暂停、继续、清空、停止、横竖屏、耳机及拔插 USB。重新连接 USB 后重新执行 `connect-phone.ps1`。暂停、清空和重连都会使用新会话，不补播断开期间的旧音频。
12. 服务终端按 Ctrl+C 正常结束，释放模型进程和临时盘符。强制结束进程树可能跳过清理；若下次报告端口被占用，应确认并关闭本项目残留进程，不要杀死未知服务。

模拟后端仍由 `scripts/start-backend.ps1` 启动，原 `.env` 的默认 `PROVIDER=mock` 不会被模型启动脚本改写。启动脚本只为本次进程选择本地模式。

## 模型与依赖

已经使用本项目下载的权重，不需要重复下载：

| 用途 | 本地位置 |
| --- | --- |
| Whisper CTranslate2 权重 | `evaluation/models/whisper-turbo/` |
| Hy-MT2 Q4_K_M 权重 | `evaluation/models/hy-mt2/Hy-MT2-1.8B-Q4_K_M.gguf` |
| llama.cpp CUDA 12 Windows 运行库 | `.tools/llama-b11979/` |
| 独立 Python 环境 | `evaluation/.venv-models/` |
| 原始下载版本、校验值 | `evaluation/model-manifest.json` |

本机 Python 环境已装好。在重建环境时，先按 `evaluation/README.md` 准备已固定的模型依赖和 NVIDIA CUDA wheel，再安装：

```powershell
.\evaluation\.venv-models\Scripts\python.exe -m pip install -r backend/requirements-local.txt
```

PyAV 保持 16.1.0，避免先前已经确认的不兼容问题。系统还需要兼容的 NVIDIA 驱动。`LOCAL_ASR_PATH`、`LOCAL_LLAMA_PATH`、`LOCAL_TRANSLATION_PATH` 可覆盖默认位置；`LOCAL_LLAMA_PORT` 默认 8788。中文工作目录由启动器临时映射到空闲 ASCII 盘符，正常退出时移除。

完整已测依赖快照另存为 `backend/requirements-local-lock.txt`，包含本机 NVIDIA wheel 和测试工具；重建相同 Windows/Python 环境时可以使用该文件固定全部版本。

`start-local-backend.ps1 -Device cpu` 可明确选择 CPU，但此前实测 CPU 识别慢于实时播放，仅适合排查，不作为实时方案。

## 流式行为与边界

- 输入仍为 16 kHz 单声道 PCM16，标准 100 ms 帧。分句器使用 32 ms Silero v6 VAD 块，每条会话独立隐藏状态。
- 开始说话保留约 400 ms 前导音频，以容纳较弱的词首；连续静音约 600 ms 后生成最终句。少于约 240 ms 的孤立声音不单独送入识别。
- 每约 1.2 秒重识别当前句；临时字幕仅显示相邻两次识别共同的前缀，至少 4 个字符。首个短片段不直接翻译，减少过早乱猜；最终识别仍可更正临时结果。这会增加首条临时字幕的等待时间。
- 连续说话最长约 8 秒强制切句，最多超过一个 VAD 块。当前切分无重叠以避免重复句；边界词仍可能丢失，尚未实现带对齐的重叠拼接。
- 后端只保留最多 4 个待处理句，同句新版本覆盖尚未处理的旧版本；计算超载时返回明确错误并终止会话，不无限累积音频。
- 一个本地模型服务只接纳一条会话，识别和翻译分别串行。翻译上下文 2048 token，单次最多 256 个输出 token；截断结果不作为完整译文发布。
- 停止或断开后立即使旧回调失效并清空音频缓冲。已经进入原生推理的调用不能强制取消，允许其结束，但不再发布到旧会话。
- 翻译指令要求保留施受关系、否定、时间、粗口和性相关词，不额外打码或委婉化。指令无法保证模型永远不误译或拒绝，真实成人影片尚未验收。
- 服务默认不保存音频、字幕或提示词。评测脚本是明确例外：仅使用公开测试样本，把结果写到 `evaluation/results/` 供复核。

## 可复现的检查

后端自动测试不加载模型，可以在普通后端环境执行：

```powershell
Set-Location backend
.\.venv\Scripts\python.exe -m pytest -q
```

真实模型完整回放验证需先关闭已有后端，在项目根目录执行：

```powershell
.\evaluation\.venv-models\Scripts\python.exe evaluation/run_streaming_check.py
```

脚本自行启动真实模型后端，按实时速度上传现有 10 段公开 WAV，检查每段有最终字幕，再新建 epoch 上传 6 秒静音，最后正常关闭服务并检查端口释放。报告为 `evaluation/results/streaming-local-stable.json`。仅统计回环网络链路，不能当作手机延迟或准确率。

服务已经运行时可以只执行 `evaluation/streaming_smoke.py`；它不会替调用者关闭服务。使用 `--repeat` 可延长回放测试，但重复同样样本不能证明不同影片、背景音乐或成人对白的准确性。
