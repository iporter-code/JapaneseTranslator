# 手机直接联网访问家里电脑

## 使用方式

手机只安装本项目的“日语实时字幕”APK。电脑运行模型和一个便携的 HTTPS 网络通道，手机通过流量、外面的 Wi-Fi 或家中 Wi-Fi 直接连接。手机不需要 USB、Tailscale、VPN、Google 服务或单独的组网软件。

当前建议使用 0.3 APK，包含字幕保留、透明度、原文开关、后台重连和压缩传输修复。默认“本机演示”仍是固定字幕，真实翻译时要选择“连接翻译服务”。

此前尝试的 Tailscale 配置已不作为本方案依赖。电脑上曾安装的 Tailscale 客户端不参与本次连接；手机无需安装或登录它。

## 电脑启动

在项目根目录执行：

```powershell
.\scripts\start-internet-backend.ps1 -Background
```

首次运行需要下载便携 `cloudflared` 到项目 `.tools/cloudflared/`，脚本校验官方公布的 SHA256。它在电脑后台提供通道，无需手机安装软件，也不要求 Cloudflare 账号或自有域名。

等待模型加载完成和公网健康检查通过，终端会显示：

```text
Phone server address: https://若干单词.trycloudflare.com
Ready: ...
```

最近一次地址也保存在 `.tools/internet-endpoint.json`，不含应用访问令牌。`ready=true` 表示启动时公网已连通；不能据此保证之后始终在线。退出时正常流程会标记 `ready=false`。

电脑需要保持开机、连接互联网、运行模型服务，并避免休眠。0.3 增加后台运行模式：使用 `-Background` 后可以关闭启动终端，服务继续运行；停止用 `scripts/stop-internet-backend.ps1`，已实测能正常关闭本次创建的后端与通道。没有加后台参数时仍以前台方式运行。现阶段只接纳一条模型会话；开始新实例前先停止旧的同端口后端，脚本会拒绝占用未知服务。

## 手机第一次配置

1. 打开已安装的“日语实时字幕”，选择“连接翻译服务”。
2. 后端地址填写电脑终端显示的完整 `https://...trycloudflare.com` 地址，不要再填 `127.0.0.1`，也不要加 `/health`。
3. 访问令牌填写本机 `backend/.env` 中 `APP_ACCESS_TOKEN` 的值，点击保存。若之前已保存同一令牌，留空即可保留。
4. 点击“授权并开始”，完成悬浮窗、录音与系统捕获授权，切换到夸克播放日语影片。
5. 应用应显示“正在翻译”，输入音量随声音变化，字幕随真实对白改变。无声音时先检查采集权限和目标 App 的限制。
6. 可先在手机浏览器打开 `https://你的地址/health`。若看到 `provider=local`、`ready=true`，说明手机能到达服务；仍不代表夸克音频已采集成功。

这是首次配置地址和令牌后直接联网使用的方案。当前未做地址自动发现；免费临时通道重启后会换地址，换地址时需要在 App 更新一次。需要长期固定地址时再配置命名通道和域名，不应把当前临时地址当作永久地址写死在 APK 中。

## 通道与隐私

- 链路为：手机 HTTPS/WSS → Cloudflare → 电脑本机后端 → 本机 Whisper/Hy-MT2 → 手机字幕。
- 音频经过第三方网络通道转发，模型推理在电脑上进行。HTTPS 在 Cloudflare 边缘终止，再通过通道连接电脑；不宣称是手机至电脑全程只有双方能够解密。
- 后端本身继续只监听 `127.0.0.1:8765`，没有开放模型端口或项目文件目录，也不需要路由器端口映射。
- 请求识别翻译必须提供应用访问令牌，WebSocket 使用随机会话令牌。地址本身不是访问令牌；不要公开 `.env`。
- 模型服务默认不保存音频、字幕正文或提示词。明确运行的公开样本评测脚本会保存测试结果，不读取私人影片。

## 实际限制

Cloudflare Quick Tunnel 是免费、免账号的临时测试通道，没有在线时间保证，地址每次启动可能变化，并有请求数等限制。这里使用 WebSocket，不使用 Quick Tunnel 不支持的 SSE；未启用会要求浏览器登录的邮件认证，因为原生 App 使用自己的访问令牌。

公网质量取决于电脑宽带、手机网络及中转路径。国内不同运营商的可达性和延迟需真机验证，不能用电脑上的回环或公网回放替代手机流量测试。音频上传和返回字幕会消耗流量；系统或夸克禁止内部采音时，网络通道不能解除该限制。

## 验证与停止

启动后自动运行公开样本测试，并保持服务在线：

```powershell
.\scripts\start-internet-backend.ps1 -SelfTest
```

只验证一次、随后正常关闭服务与通道：

```powershell
.\scripts\start-internet-backend.ps1 -SelfTest -CheckOnly
```

公开样本报告保存到 `evaluation/results/streaming-internet.json`；其中 `phone_tested=false`，不会把电脑经公网回放称为手机实测。通常使用时直接运行不带 `-SelfTest` 的启动命令，避免评测占用唯一会话。

运行脚本的终端按 Ctrl+C 正常结束。启动器先关闭自己创建的外部通道，再停止本地模型服务；强制杀死整个进程树可能跳过清理。
